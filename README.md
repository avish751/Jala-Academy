# Jala-Academy
JALA Academy - SQL and Python Assignments
This repository contains a collection of solved assignments focusing on Database Management Systems (SQL) and Python Programming. These tasks are designed to build foundational skills in data manipulation, query optimization, and object-oriented programming.

📂 Project Structure
sql_assignment (2).sql: A comprehensive SQL script covering database creation, data insertion, and 89 distinct query challenges.

jala acedmy (3).py: A multi-topic Python script demonstrating core programming concepts, from basic syntax to advanced OOP and file handling.

📊 SQL Assignment Overview
The SQL file utilizes a relational database named jalaacedmy consisting of three tables: salespeople, cust (customers), and orders.

Key Features Covered:
DML & DDL: Creating tables, primary keys, and inserting data.

Filtering: Advanced usage of WHERE, IN, BETWEEN, LIKE, and REGEXP.

Aggregations: SUM, AVG, MAX, MIN, and COUNT with GROUP BY and HAVING clauses.

Joins: Inner Joins, Self-Joins, and Cartesian products.

Subqueries: Correlated and non-correlated subqueries, as well as EXISTS, ANY, and ALL operators.

Set Operations: Using UNION and UNION ALL to combine results.

Conditional Logic: Implementing CASE statements and IF logic within queries.

🐍 Python Assignment Overview
The Python script is organized into modules to demonstrate the following concepts:

1. Fundamentals
Variables & Scope: Handling global vs. local variables.

Data Types: Implementation of integers, booleans, characters, and floating-point numbers.

Operators: Arithmetic, relational, and increment/decrement logic.

2. Data Structures
Lists (Arrays): Calculating totals, averages, and identifying duplicate elements.

Dictionaries: Managing key-value pairs, updating records, and nested access.

3. Object-Oriented Programming (OOP)
Inheritance: Demonstrating multi-level inheritance and method overriding.

Abstract Classes: Using the abc module to define interfaces.

Access Modifiers: Example of private fields and methods.

Constructors: Default, parameterized, and super() calls in child classes.

4. Advanced Topics
Exception Handling: Custom exception classes, try-except-finally blocks, and specific error catching (e.g., ZeroDivisionError).

File I/O: Reading, writing, and checking file permissions.

Regex: Basic pattern matching.

🚀 Getting Started
Prerequisites
SQL: MySQL or any standard SQL workbench.

Python: Python 3.x installed on your local machine.

Execution
SQL: Import the .sql file into your database management tool and execute the script to build the schema and run the queries.

Python: Run the script via terminal:

Bash

python "jala acedmy (3).py"
